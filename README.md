# Gemäldekatalog

Digitaler Katalog der erfassten Gemälde und gerahmten Arbeiten.

## Ziel

Die Sammlung wird mit Fotos, Maßen, Motivbeschreibung, Künstler-/Signaturhinweisen, Technik, Zustand, Provenienzmerkmalen und einer vorsichtigen marktbezogenen Einordnung dokumentiert.

## Arbeitsstand

Die fotografische Erfassung und Einzelkatalogisierung ist erfolgt bzw. läuft im ChatGPT-Projekt **Gemäldekatalog**. Die strukturierten Katalogdaten und Bildzuordnungen werden in den folgenden Commits in dieses Repository übernommen.

## Geplante Struktur

- `catalog/` – strukturierte Katalogeinträge
- `images/` – zugeordnete Objektfotos
- `docs/` – zusammenfassende Katalogdokumente und Exporte

Die Maße werden grundsätzlich in Zentimetern geführt; sofern vorhanden getrennt nach Werkmaß und Rahmenmaß.
